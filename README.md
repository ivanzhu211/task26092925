# task26092925

Go 库：对有序编辑计划（`Crop` / `Resize` / `BoxBlur`）做非破坏性、区域局部渲染。

- 源图为只读 `io.ReaderAt`，按行紧密排列的 RGB8，无文件头；任何操作都不改写源数据。
- `Render(reader, width, height, ops, rect)` 返回最终图像中 `rect`（坐标相对最终图）的 RGB8 字节。
- 实现先把请求矩形沿计划反向回溯，得到每一级所需的最小依赖矩形；源图只在该矩形内读取，每个中间级也只计算其依赖窗口。
- 结果与“从源图逐级处理整幅图像、最后裁剪出同一区域”逐字节相同。

数值约定：
- 三通道独立处理，无色彩空间转换。
- 缩放为像素中心对齐的双线性插值，先定四邻点与精确权重，再将越界索引夹到边缘；权重用精确整数有理运算。
- 模糊为边长 `2r+1` 的正方形窗口，越界重复边缘像素，分母恒为完整窗口面积，窗口内不提前舍入。
- 每步结束时每通道四舍五入到 8 位，恰好半整数向上（`(num + den/2) / den`）。

运行测试：

```
go test ./...
```

测试包括：小图上对 4000 组随机有效计划与随机/边缘区域与独立全帧参考逐字节核对（含连续模糊、非整数比例缩放、半整数舍入），以及 4000x3000 大图“两次模糊后缩小”中心区域的读取局部性与可重复内存/分配检查。
